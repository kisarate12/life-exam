# トップ画面用・4世界ビルボード背景画像

このフォルダに、トップ画面のフルページスクロールで使う4つの世界の背景画像を置いてください。

## 推奨ファイル名（コードから参照）

| 世界 | ファイル名 |
|------|------------|
| 空 | `sky.png` |
| 地上 | `ground.png` |
| 冥界 | `underworld.png` |
| 海 | `sea.png` |

トップのフルページスクロールでは、セクション②が空・③が海・④が地上・⑤が冥界の背景として上記を参照します。

## 使い方

- トップ画面では、4枚のうち1枚をランダムまたは固定で背景に表示する想定です。
- ビルボードサイズ（横長）の画像をそのまま置けば、`background-size: cover` などで全体に敷き詰められます。
